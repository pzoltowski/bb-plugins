# Muse Code (ACP)

Runs bb threads on Muse Code through the `muse-acp` adapter, a native bridge
between bb's Agent Client Protocol and Muse Code's own session protocol.

Muse Code arrives as a named provider with its own icon, rather than the
generic glyph a manually configured ACP agent shows.

Requires a Muse Code subscription and the `muse-acp` binary on `PATH`.
